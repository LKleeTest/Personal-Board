# LK Board

A single-file personal task board. Open `index.html` in a browser, or serve the repo with GitHub Pages.

- Lists by task type, with steps and a progress bar per task
- Long-press the + button to add a task by voice (English or Chinese, where the browser allows the microphone)
- XP, levels and daily streaks with confetti
- All Tasks view with red priority flags
- Daily Summary: a one-page report and email draft
- Bill Payments: one-off and recurring bills with due dates

Data is saved in the browser (localStorage) when the page runs outside Claude.
